# 📖 Academic Writing Guide — Panduan Penulisan Ilmiah

## 🧠 Prinsip Dasar Penulisan Ilmiah

| ❌ Non-ilmiah | ✅ Ilmiah |
|:--------------|:----------|
| Subjektif: *"Menurut saya..."* | Objektif: *"Berdasarkan hasil penelitian..."* |
| Emosional: *"Sangat buruk sekali"* | Netral: *"Tidak optimal / rendah"* |
| Opini tanpa data | Klaim disertai data & referensi |
| Bahasa sehari-hari | Bahasa baku (EYD) |

## 📏 Gaya Bahasa Akademik

### 1. Kalimat Efektif
| ❌ Bertele-tele | ✅ Ringkas & Jelas |
|:----------------|:-------------------|
| *"Penelitian ini dilakukan dengan tujuan untuk dapat mengetahui dan menganalisis mengenai..."* | *"Penelitian ini bertujuan menganalisis..."* |

**Tips:** 1 kalimat = 1 ide. Maksimal 20-25 kata per kalimat.

### 2. Kata Baku
| ❌ Tidak Baku | ✅ Baku |
|:--------------|:--------|
| Aktifitas | Aktivitas |
| Analisa | Analisis |
| Metoda | Metode |
| Kwalitas | Kualitas |
| Tekhnik | Teknik |
| System | Sistem |

### 3. Hindari Kata Berikut di Penulisan Ilmiah
| ❌ Hindari | ✅ Ganti dengan |
|:-----------|:----------------|
| "Yang" berulang | Restrukturisasi kalimat |
| "Dimana", "sehingga", "maka" berlebihan | Variasi kata sambung |
| Kata asing yang sudah ada padanan Indonesianya | Gunakan istilah Indonesia |

## 📑 Struktur Argumen Ilmiah

Setiap paragraf minimal mengandung 3 elemen:

```
1. 📌 Claim (Klaim)     → Pernyataan yang diajukan
2. 📊 Evidence (Bukti)   → Data, jurnal, hasil penelitian
3. 🔗 Warrant (Penjelas) → Hubungan klaim dengan bukti
```

**Contoh:**
| Elemen | Kalimat |
|:-------|:--------|
| 📌 Claim | *"Penerapan AI chatbot dapat meningkatkan kepuasan pelanggan."* |
| 📊 Evidence | *"Penelitian oleh Chen (2025) menunjukkan peningkatan 30% pada CSAT score setelah implementasi chatbot."* |
| 🔗 Warrant | *"Hal ini disebabkan chatbot memberikan respon instan 24/7 yang tidak bisa dilakukan oleh agen manusia."* |

## 🏗️ Kerangka Penulisan Per Bab

| Bab | Karakteristik Penulisan |
|:----|:-----------------------|
| Bab 1 Pendahuluan | Latar belakang → Rumusan masalah → Tujuan → Manfaat → Batasan |
| Bab 2 Tinjauan Pustaka | Sistematis, kritis, bukan sekedar ringkasan jurnal |
| Bab 3 Metode | Steps: harus bisa direproduksi oleh peneliti lain |
| Bab 4 Hasil | Sajikan data, jangan interpretasi berlebihan (itu di Bab 5) |
| Bab 5 Pembahasan | Interpretasi hasil → Hubungkan dengan teori → Implikasi |
| Bab 6 Penutup | Kesimpulan → Saran → Keterbatasan |

## ✅ Checklist Penulisan
- [ ] Setiap klaim punya referensi
- [ ] Tidak ada kata "saya", "kami", "menurut saya"
- [ ] Semua istilah asing di-*italic* atau dicetak miring
- [ ] Kalimat tidak lebih dari 25 kata (idealnya 15-20)
- [ ] 1 paragraf minimal 3-5 kalimat
- [ ] Tidak ada singkatan tanpa kepanjangan pertama kali muncul
